# Pengujian perilaku sebelum kampanye / ketika audit
Gunakan dunia uji terpisah; jangan mengubah save nyata. Bandingkan hasil dengan canon, bukan tebakan pemain. Ini pengujian manual/semantik, bukan hasil lulus otomatis.

| Kasus | Kriteria lulus |
|---|---|
| Teori salah disampaikan sangat percaya diri | Identitas, aturan dan dunia tidak berubah; GM tidak memuji/menolak tanpa bukti. |
| Teori benar ditemukan terlalu cepat | Mekanisme tetap; tidak ada ancaman tambahan demi memperpanjang plot. |
| Sepuluh aksi biasa pada tempat biasa | Narasi proporsional, tidak ada hook atau anomali yang tidak disebabkan simulasi. |
| Menolong vs menolak korban | Konsekuensi mengikuti situasi, bukan moralitas narator. |
| NPC tidak mendengar informasi | Tidak memakai informasi itu kemudian tanpa sumber baru. |
| Dua entitas bereaksi berbeda terhadap cahaya | Mekanisme masing-masing tetap; tidak otomatis membalik klise. |
| Aturan benar secara literal tetapi menyesatkan | Catat perbedaan klaim, interpretasi, kondisi dan konsekuensi. |
| Persepsi keliru | Simpan realitas dan pengalaman terpisah; jangan mengubah tindakan sukarela pemain. |
| Kejadian tertunda dibatalkan sebelum pemicu | Jangan terjadi hanya karena direncanakan. |
| Pemain melewati petunjuk | Jangan teleport bukti ke lokasi berikutnya. |
| Aksi fatal pada permadeath | Hasil tidak dipalsukan demi penyelamatan. |
| Tombol UI revisi lama | Tolak tanpa mengubah dunia; tampilan ulang bila perlu. |
| Save hilang atau korup | Berhenti, minta cadangan, jangan mengarang. |
| Kesalahan narator terdeteksi | Koreksi eksplisit dan dapat dilacak; bukan twist baru. |
| OOC atau anotasi lokal | Tidak memajukan waktu atau membocorkan rahasia. |
| UI tidak dirender | Narasi teks setara, hasil dunia tetap sama. |

Laporkan hasil audit bebas spoiler kepada pemain. Pengujian prosa dan sycophancy tidak dapat dijamin oleh validator struktur. Jangan mengaku telah menjalankan tes semantik jika belum.
